# Novus Deploy - Windows Edition
This is a Windows Version of [NovusDeploy](https://github.com/Nullora/NovusDeploy),
A local project manager to keep your code up-to-date across multiple files.

- It uses Alternate Data Streams to staple data onto your file's metadata, allowing Ndeploy to track them and recognize them with 0 overhead.

## Requirements
### Executable
- You just need to be on windows since NTFS ADS is specific to windows, download code/build/ndep.exe and put it in PATH. [tutorial](https://windowsloop.com/how-to-add-to-windows-path/).
### Actual Uncompiled Code
- You need `Make`, `gcc` 


## Functions
```bash
ndep sign {file_name} {library_name}
```
This function signs a specific file using NTFS Alternate Data Streams (big fancy word for attaching data to file without changing its contents). This makes it so even if the file changes names or location, it will always maintain the sign.
```bash
ndep unsign {file_name}
```
This function unsigns a file and deletes the Additional Data Streams previously generated.
```bash
ndep import {library_name}
```
This function imports a library into current working directory and adds it to a local database. Ndep always knows how many copies of the library have been distributed and where exactly.
```bash
ndep update {library_name}
```
This function updates an imported library. It pulls the update from the libraries database. Due to the metadata generated by Ndep, it can recognize merge conflicts and halt updates without ever opening the content of the file, just using the hashed bytes added to the metadata.
```bash
ndep push {library_name}
```
This function pushes a new update to the main libraries database. (Again, smart merging using the hashed bytes in the metadata)
```bash
ndep rename {library_name} {new_name}
```
This function renames the library and updates the signing on every single tracked file.

## For Who
If you have single header libraries that you share across multiple projects (like me) you probably wanna keep them up to date and not manually fix bugs everywhere once u spread them. Ofc you could just make a quick copy-paste script, or you could make it much fancier and cleaner using Ndep!
